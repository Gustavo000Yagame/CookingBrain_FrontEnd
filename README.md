# 🍽️ CookingBrain - Front-end

O **CookingBrain** é um sistema ERP desenvolvido para otimizar a gestão de restaurantes, oferecendo uma interface moderna, intuitiva e responsiva para o gerenciamento de estoque, produtos, pedidos, fornecedores, clientes e indicadores financeiros.

## 📖 Sobre o Projeto

O Front-end foi desenvolvido utilizando Vue.js e é responsável por toda a experiência do usuário, consumindo uma API REST desenvolvida em Java Spring Boot.

A aplicação está hospedada na **Vercel**, garantindo alta disponibilidade, carregamento rápido e facilidade de acesso.

##  Principais Funcionalidades

- Login seguro
- Dashboard executivo
- Controle de estoque
- Gerenciamento de pedidos
- Controle de usuários
- Relatórios
- Gráficos estatísticos
- Análise de markup
- Interface responsiva

## 🛠 Tecnologias

- Vue.js 3
- JavaScript
- HTML5
- CSS3
- Tailwind CSS
- Axios
- Vue Router
- Pinia
- Chart.js
- Vite

## ☁️ Hospedagem

O Front-end encontra-se hospedado na plataforma **Vercel**, permitindo deploy automático sempre que novas alterações são enviadas para o repositório.

      ▼
